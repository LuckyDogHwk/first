## 📖 项目简介

在大地图中操控球球吞噬彩豆、孢子和其他玩家，不断变大，争夺排行榜第一。

- **玩家控制**：WASD 移动、空格分身、M 吐球
- **12 个 AI 对手**：独立寻路、追逐/逃跑策略、会分身和吐球
- **完整游戏机制**：分身合并、刺球爆炸分裂、孢子滑行、排行榜

## 🏗️ 架构设计

```
┌─────────────────────────────────────────┐
│                  Game                    │  ← 状态管理 (Menu / Playing)
│   Init()  Run()  HandleEvents()         │     主循环、输入处理、UI渲染
└────────────────┬────────────────────────┘
                 │
┌────────────────▼────────────────────────┐
│                 World                    │  ← 世界管理器
│   Update()  ResolveCollisions()         │     实体管理、碰撞检测
│   TrySplit()  TrySpit()  UpdateBots()   │     分裂/吐球、AI行为
└──┬──────────┬──────────┬───────────────┘
   │          │          │
┌──▼──┐  ┌───▼───┐  ┌──▼──────┐
│Ball │  │Pellet │  │ThornBall│        ← 游戏实体
│物理 │  │彩豆   │  │刺球(陷阱)│
└─────┘  └───────┘  └─────────┘
```

### 核心类职责

| 类 | 职责 |
|---|---|
| `Game` | 游戏入口：窗口管理、菜单系统、输入事件分发、BGM 播放 |
| `World` | 世界逻辑：实体生成/销毁、碰撞检测(`ResolveCollisions`)、物理模拟、AI 控制 |
| `Ball` | 球体实体：质量→半径转换、速度衰减、皮肤贴图、分裂/合并计时器 |
| `Pellet` | 彩豆（食物）：散布在地图中的可拾取物 |
| `ThornBall` | 刺球（陷阱）：被大球吞噬后使其爆炸分裂为 8 个分身 |

### 关键技术点

- **碰撞检测**：球-球 70% 重叠判定、球-刺球覆盖半径判定、点到线段距离（分身路径扫豆）
- **同主人球相互作用**：冷却期推挤 + 速度同步 → "相对静止"效果；冷却结束合并
- **AI 状态机**：寻路彩豆/弱小球 → 追猎 → 躲避大球；多分身时向质心聚拢
- **刺球爆炸**：中心球 + 8 个等质量小球呈圆形均匀分布，质量守恒

## 🚀 本地构建

### 环境要求

- Visual Studio 2022 (含 C++ 桌面开发工作负载)
- SFML 2.6.2（已包含在 `third_party/` 中）
- Windows 10+

### 构建步骤

1. 双击 `球球大作战.sln` 在 Visual Studio 中打开
2. 选择 `Debug x64` 或 `Release x64`
3. 按 `Ctrl + Shift + B` 编译
4. 按 `F5` 运行

---

## 🎯 操作说明

| 按键 | 功能 |
|------|------|
| `W` `A` `S` `D` | 移动方向 |
| `空格` | 分身（向移动方向分裂，最多 16 个） |
| `M` | 吐孢子（向移动方向弹出） |
| `R` | 死亡后重新开始 |
| `ESC` | 返回主菜单 |
